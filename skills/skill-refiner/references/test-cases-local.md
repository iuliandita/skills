# Local Behavioral Test Cases

Policy for `references/test-cases-local.md`:

- Local cases exist only for skills that have no canonical section in
  `references/test-cases.md`.
- Canonical cases always take precedence when a skill has both.
- Local cases are never used to score the run that creates them.
- This file is immutable during phase 1. Saving or promoting local cases happens only in
  phase 2 or a separate reviewed change.
